# Re:Place 추가 플랫폼 후보

현재 Re:Place에 연결된 플랫폼 외에, 추후 수집 연동을 검토할 후보 목록입니다.
이 문서는 **후보 조사만** 기록하며, 아직 크롤러/API 연동은 진행하지 않습니다.

## 우선 검토 후보

| 플랫폼 | 공식 사이트 | 확인된 특징 | 수집 검토 포인트 |
| --- | --- | --- | --- |
| 디너의여왕 | https://dinnerqueen.net/ | 맛집/지역형 중심, 블로그·릴스 등, 지역/마감/신청·모집 데이터 노출 | 캠페인 목록 네트워크 요청 및 페이지네이션 구조 확인 |
| 미블 | https://www.mrblog.net/ | 지역/배송 캠페인, 블로그·인스타, 제공내역·신청/모집 노출 | 목록 API/XHR 여부 및 세부 지역 구조 확인 |
| 리뷰플레이스 | https://www.reviewplace.co.kr/ | 제품·지역·기자단·구매평 캠페인, 대규모 캠페인 데이터 | 캠페인 카테고리별 목록 엔드포인트와 중복 ID 구조 확인 |
| 포블로그 | https://4blog.net/ | 방문/배송, 블로그·인스타·릴스·유튜브·쇼츠·틱톡·스레드 등 채널 폭이 넓음 | 지역/매체 필터가 잘 구조화되어 있어 우선 분석 가치 높음 |
| 리뷰어스 | https://kr.reviewus.co.kr/ | 블로그·인스타, 배송형 등 캠페인 운영 | 목록/상세 페이지 구조와 캠페인 ID 안정성 확인 |

## 우선순위 제안

1. **포블로그**
   - 지역/매체/방문·배송 분류가 잘 나뉘어 있어 Re:Place 공통 모델에 맞추기 좋음.
2. **디너의여왕**
   - 캠페인 규모가 크고 지역·신청·모집·마감 데이터가 명확함.
3. **미블**
   - 지역형/배송형과 제공금액 정보가 잘 보여 필터 데이터 확장에 유리함.
4. **리뷰플레이스**
   - 캠페인 수가 많고 유형이 다양하지만 구조 분석 범위가 더 클 가능성 있음.
5. **리뷰어스**
   - 후보 풀 확장용으로 유효. 앞 플랫폼 분석 후 연동 난이도 비교.

## 연동 전에 확인할 것

- robots.txt / 이용약관 / 공개 데이터 접근 범위
- 목록 데이터가 HTML인지, 공개 XHR/API인지
- 캠페인 고유 ID의 안정성
- 페이지네이션 방식
- 지역 / 매체 / 캠페인 유형 / 제공내역 / 마감일 원본 필드
- 인증 토큰 필요 여부
- 요청 빈도 제한 및 차단 위험
- 동일 광고주의 중복 캠페인 판별 가능 여부
