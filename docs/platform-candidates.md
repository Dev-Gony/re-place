## 후순위 / 컷

- 파블로: 약 600대 규모로 1차 700건 컷 미달
- 놀러와체험단: 약 400대 규모로 후순위
- 링블 및 그 이하 규모 플랫폼: 유지보수 대비 공급량이 작아 1차 확장에서 제외
- 리뷰노트: 모집량은 크지만 운영정책상 자동수집/외부 게시 제한이 확인되어 blocked 유지
- 레뷰: 인증 API 경계 때문에 공식 API/제휴 또는 공개 전체목록 경로 전까지 보류
- 슈퍼멤버스: 앱/인증 경계 때문에 보류

## 별도 중요 과제: 기존 대형 소스 커버리지

플랫폼 수만 늘리는 것보다 기존 대형 소스의 누락을 줄이는 것이 더 큰 효과일 수 있다.

- 디너의여왕: 최근 운영 배치 동기화는 38건. 공식 목록 전체 규모 대비 초기 페이지/렌더만 수집 중인지 조사 필요.
- 리뷰플레이스: 카테고리별 첫 목록만 수집하는 구조인지 페이지네이션 재검증 필요.
- 미블: 페이지 순회가 이미 구현되어 있으나 2페이지에서 신규 0건으로 종료되는 현재 응답이 실제 전체 목록인지 점검.
- 리뷰어스: 최근 동기화 5건으로 공급량 대비 효용을 재평가. 계속 소량이면 운영 우선순위를 낮출 수 있음.

## 포블로그 RPL-039 관측

- 공개 비로그인 목록 사용 가능
- 상세 링크: `/campaign/{numeric-id}/`
- 목록은 JavaScript 무한스크롤
- `?page=2`, `?page=3` 같은 단순 page query는 동일한 초기 목록을 반환해 전체 수집 방법으로 사용할 수 없음
- 공개 분할 경로: 전체, 배송, 기자단, 당근, 지역별 목록
- 전체 client-side 로딩 계약이 확정되기 전에는 production collector로 활성화하지 않음

## 연동 공통 체크

- robots.txt / 이용약관 / 공개 데이터 접근 범위
- 목록 HTML 또는 공개 XHR/API 계약
- 캠페인 고유 ID 안정성
- 페이지네이션 / 무한스크롤 종료 조건
- 지역 / 매체 / 유형 / 제공내역 / 마감일
- 인증 토큰 필요 여부
- 요청 빈도 및 차단 위험
- 동일 광고주의 매체별 중복 여부
- 실제 모집 규모 대비 수집 커버리지
