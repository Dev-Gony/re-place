## 제품 단계

| 단계 | 검증할 가치 | 범위 |
|---|---|---|
| V1 | 필요한 체험단을 빠르고 정확하게 찾기 | 검증된 주요 소스, 블로그 중심, 원문 연결, 날짜/혜택/지역 품질 |
| V1.1 | 탐색 결과가 내 업무 기록으로 이어지기 | 인증, 관심 저장, 직접 등록, 원문 스냅샷 |
| V2 | 작성 마감과 미정산을 놓치지 않기 | 달력, 할 일, 제출, 제공 내역과 실제 현금 입금 분리, 웹/앱 동기화 |
| V3 | 운영·작성 품질 개선에 대한 지불 의사 | 이용 가능한 근거 데이터, 설명 가능한 자체 지표, 사용자 승인형 작성 보조 |
| V4 | 광고주와 크리에이터 간 반복 거래 | 모집·선정·검수·정산·분쟁, 수동 매칭 수요 검증 후 구현 |

## 상태 표기

`OBSERVED`는 관측 완료이지 정상 판정이 아니다. `PARTIAL/BLOCKED`는 구현/조사의 일부는 끝났지만 인수 조건이 남은 상태다. 구현, 병합, 배포, 운영 검증 완료를 구분한다.
