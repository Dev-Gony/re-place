# RPL-060: 리뷰노트 공개 노출 임시 차단

## 배경

관리자 검토·선별 노출 기능을 만들기 전까지 리뷰노트 캠페인을 공개 탐색에서 숨긴다. 현재 `reviewnote-public-list` 수집 데이터는 운영 공개 검색에 노출되고 있다. 원본 캠페인과 사용자가 이미 만든 찜·내 체험단 기록은 삭제하지 않는다.

## 목표

- 공개 플랫폼 필터에서 `리뷰노트`, `리뷰노트(공개목록)`을 제외한다.
- 직접 query parameter를 보내도 공개 목록과 인라인 상세 데이터에 리뷰노트가 포함되지 않게 서버 SQL에서 차단한다.
- 공개 전체 건수와 최신 수집 시각도 같은 가시성 조건을 사용한다.
- 개인 찜·기록 생성에 필요한 기존 campaign snapshot 조회는 유지한다.
- 리뷰노트 수집과 원본 행은 유지하고 다른 플랫폼에는 영향을 주지 않는다.
- 관리자 노출 관리의 최소 RBAC·데이터 모델·전환 방안을 문서화한다.

## Acceptance Criteria

1. 공개 플랫폼 선택지에 리뷰노트 별칭 두 개가 나타나지 않는다.
2. 공개 캠페인 목록·건수·전체 공개 집계 SQL 모두 임시 비공개 플랫폼 조건을 공유한다.
3. 리뷰노트 query parameter는 허용 플랫폼 필터에서 제거되고 리뷰노트 행을 반환하지 않는다.
4. `getCampaignSnapshot`과 소유자별 workspace 조회에는 공개 가시성 조건을 추가하지 않는다.
5. 리뷰노트 crawler, collection gate, campaign 원본 행을 변경하거나 삭제하지 않는다.
6. 관리자 설계는 campaign 노출 관리 전용 최소 권한과 변경 이력을 포함한다.
7. lint, Node/Python tests, typecheck, production build, CI와 배포를 검증한다.

## 관리자 노출 관리 후속 설계

상세 설계는 `docs/ADMIN_CAMPAIGN_VISIBILITY.md`에서 관리한다. 이번 이슈에서는 관리자 권한을 활성화하거나 DB migration을 적용하지 않는다.

## 범위 밖

- 관리자 계정 생성·권한 부여와 Auth 설정 변경
- 운영 DB schema migration
- 모든 신규 캠페인을 즉시 수동 승인제로 전환
- 리뷰노트 수집 중단 또는 원본/개인 데이터 삭제
- 결제·외부 연동·SEBICON 변경
