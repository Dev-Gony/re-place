## 문제

CampLedger의 가치(놓친 발행·미수금 발견)를 보려면 지금은 로그인하고, 캠페인을 하나씩 등록하고, 정산을 입력해야 한다.
이미 시트로 관리하는 크리에이터에게는 첫 가치가 보이기 전에 할 일이 너무 많다.

## 목표

가입 없이 시트를 붙여넣거나 CSV를 올리면 1초 안에 다음을 보여준다.

- 마감이 지났는데 발행 URL이 없는 캠페인
- 3일 안에 마감인데 발행 URL이 없는 캠페인
- 지급 예정일이 지났는데 다 받지 못한 금액 (부분 입금 포함)
- 발행했지만 지급 예정일이 비어 있는 건, URL 대신 메모가 적힌 칸, 중복 행, 읽지 못한 값

## 비목표

- 서버 저장, 계정 생성, 운영 DB 쓰기
- `.xlsx` 직접 파싱 (시트 복사·붙여넣기 또는 CSV로 대체)
- 발행 URL 생존 확인 (서버가 임의 URL을 요청하는 SSRF 위험이 있어 별도 설계)
- 크롤링, 플랫폼 연동

## 사용자 흐름

1. `/check`에 들어온다 (헤더 "누락 진단").
2. 시트를 붙여넣거나 CSV를 올리거나 예시 페르소나 시트를 고른다.
3. 결과 요약 문장, 지표 4개, 인식한 열, 확인이 필요한 행 목록을 본다.
4. "내 체험단으로 가져오기"를 누르면 진단 결과가 브라우저 sessionStorage에 잠시 보관되고 `/my`로 이어진다 (RPL-064).
