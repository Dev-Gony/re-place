## 범위와 안전 조건

RPL-040의 공개 카탈로그 기술 검증 다음 단계로, 실제 유형별 표본 정확도와 공개 정책을 검토한다. 공개 비로그인 GET만 사용하며 로그인, 우회, 운영자 연락, production DB 쓰기, collector 활성화는 하지 않는다.

## 수정한 정확도 결함

실제 API에서 `cp_opt_text`가 `cp_opt_name` 전체를 포함하는 경우 두 값을 단순 연결하면 같은 보상 설명이 반복됐다. 보상 후보끼리 포함 관계가 있으면 더 긴 상위 문구만 남기고, 별도 포인트 값은 유지한다. fixture 회귀 테스트로 구매/방문형 중복 방지를 고정한다.

## 정책 검토

- `https://assaview.co.kr/robots.txt`: `User-agent: *`, `Allow: /`. 접근 허용일 뿐 재사용·상업 이용 허가는 아님.
- `policy.php?code=amago_agreement`: 회사 사전 승낙 없는 서비스 정보의 복제·유통·상업적 이용을 금지하는 조항 확인.
- `policy.php?code=agreement`: 회사 동의 없는 영리 목적 서비스 이용을 금지하는 조항 확인.
- privacy 문서와 공개 화면에서 자동 수집 또는 제3자 검색 서비스 재게시를 명시적으로 허용하는 근거는 확인하지 못함.

## 결정

아싸뷰 상태를 `paused-policy`로 유지한다. parser와 hosted dry-run은 기술 검증 자산으로 보존하되 `crawlers/run_all.py`, production source registry, 스케줄 수집에는 연결하지 않는다.

재활성화에는 권리자/운영자의 서면 허가, 재사용 범위가 명시된 공식 API/데이터 인터페이스, 또는 허용 범위가 명확해진 약관과 운영 검토 중 하나가 필요하다. 운영 활성화는 별도 승인과 PR로만 수행한다.
