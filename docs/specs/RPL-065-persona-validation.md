## E2E 시나리오 (11/11 통과)

1. 페르소나 4종: 예시 클릭 → 지표 4개가 기대값과 일치. 주는 쪽 페르소나는 "리뷰를 올리지 않은 리뷰어", "지급하지 않은 돈" 문구

3. `.xlsx` 업로드는 붙여넣기·CSV 안내로 거절
4. 열 이름 없는 붙여넣기는 이유 안내
5. "내 체험단으로 가져오기": sessionStorage에 6건 보관, `/my?import=ledger#ledger-import` 링크
6. 페이지 로드 후 비 GET 요청과 `/api` 요청 0건 (붙여넣은 내용이 서버로 가지 않음)

8. 모바일 390px: 가로 스크롤 없음, 예시 선택 시 결과로 스크롤

## 남은 공백 (다음 단계 후보)

1. **열 직접 지정**: 자유로운 헤더를 쓰는 시트는 지금 진단하지 못한다. "없는 열"에서 사용자가 열을 골라 주는 UI가 가장 효과가 클 것으로 본다 (v2 커넥터의 첫 단계).
2. **재가져오기 중복**: 같은 시트를 두 번 가져오면 기록이 두 번 생긴다. 가져오기 전 기존 기록과 제목+플랫폼 비교 안내가 필요하다.
3. **발행 URL 생존 확인**: 서버가 사용자 입력 URL을 요청하는 기능이라 허용 도메인·타임아웃·크기 제한 설계(SSRF 방지)가 먼저다.
4. **알림 채널**: 지금은 `/my`에 들어와야 보인다. 메일·푸시는 범위 밖이다.
5. **`.xlsx` 직접 읽기**: 붙여넣기·CSV로 대체 중. 의존성 추가가 필요하다.
6. **실사용 검증**: 페르소나 결과는 가설 검증일 뿐이다. 본인 실제 시트 1개로 먼저 돌려보는 것을 권한다.
