# RPL-019 월간 달력

기준일: 2026-09-29  
기준 main: `052350c14c633f2eb359a35fe9c459cb53ece1fa`

## 목표

RPL-018에서 만든 개인 일정 데이터를 월간 단위로 훑을 수 있게 한다.
새 DB 구조를 만들지 않고 기존 `user_campaign_tasks`와
`user_campaign_records.deadline_at`을 같은 날짜축에 표시한다.

## 동작

- 일정 화면 기본값은 달력
- 목록 보기로 언제든 전환 가능
- 이전 달 / 오늘 / 다음 달 이동
- 6주 42칸 고정
- 할 일과 캠페인 마감 구분
- 완료된 할 일은 약화 표시
- 한 날짜의 이벤트는 최대 3개까지 노출하고 나머지는 개수로 축약

## 날짜 경계

오늘 날짜는 브라우저 시계에 의존하지 않는다.
`app/my/page.tsx`에서 `Asia/Seoul` 기준 날짜 키를 생성해
클라이언트에 전달한다.

task 및 campaign timestamp 역시 달력 키로 변환할 때
`Asia/Seoul`을 명시한다.

## 모바일

모바일에서 달력은 자체 영역 안에서만 가로 스크롤된다.
페이지 전체 폭은 늘리지 않는다.

## 제외 범위

- 날짜 클릭 상세 패널
- 드래그 앤 드롭 일정 변경
- 반복 일정
- 알림
- 주간/일간 보기

이 기능들은 실제 사용 패턴을 본 뒤 후속 이슈로 분리한다.
